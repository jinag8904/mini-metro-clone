## 🎮 어떤 게임인가요?

지도 위에 역이 하나둘 생겨나고, 각 역에는 **가고 싶은 목적지 모양**을 띄운 승객이 계속 도착합니다.
플레이어는 마우스로 역과 역을 이어 **노선을 그리고**, 그 위에 **열차를 배치**해 승객을 목적지까지 실어 나릅니다.

- 승객은 자기가 원하는 **모양(●, ■, ▲)의 역**에 도착하면 내립니다.
- 역마다 수용 인원이 정해져 있고, **넘치면 제한 시간 타이머가 돌아갑니다.**
- 타이머가 끝나면 그 역은 폐쇄되고 **게임 오버** — 그때까지 실어 나른 승객 수가 점수입니다.

역은 시간이 지날수록 계속 늘어나기 때문에, "지금 이 노선을 어디로 연장할 것인가"를 매 순간 다시 판단해야 하는
**공간 설계 + 자원 배분 + 타임 어택**이 한 번에 걸린 구조입니다.

## 🕹 조작

| 조작 | 동작 |
|---|---|
| 역 클릭 후 드래그 | 새 노선 만들기 |
| 노선 끝 손잡이 드래그 | 기존 노선 연장 / 단축 |
| 노선 중간 클릭 후 드래그 | 노선 중간에 역 끼워 넣기 / 빼기 |
| 하단 노선 버튼 클릭 | 해당 노선 전체 삭제 (배치한 열차·객차는 반환) |
| 자산 아이콘 → 노선으로 드래그 | 열차 · 객차 · 고속열차 배치 |
| 자산 아이콘 → 역으로 드래그 | 해당 역을 환승역으로 승격 |
| ⏸ / ▶ / ⏩ | 일시정지 · 재생 · 2배속 |

## ⚙️ 핵심 시스템

### 노선
- 최대 **7개 노선**, 노선당 최대 **4대의 열차**(일반·고속 합산). 처음에는 3개 노선만 쓸 수 있습니다.
- 두 역을 이으면 *Mini Metro*처럼 **직선 + 45° 대각선**으로 꺾인 경로가 자동으로 만들어집니다.
- 첫 역과 마지막 역을 이으면 **순환선**이 되어 열차가 한 방향으로 계속 돕니다.
- 운행 중에 노선을 고쳐도 열차가 순간이동하지 않습니다. 가던 지점이 새 노선에 남아 있으면 그대로 이어 달리고,
  지워졌으면 그 지점까지 간 뒤 새 노선과 만나는 곳에서 합류합니다.

### 승객 & 환승
- 열차는 역에 설 때 **BFS(너비 우선 탐색)** 로 "이 방향으로 가면서, 환승까지 포함해 목적지 모양에 닿을 수 있는가"를 확인하고 그런 승객만 태웁니다.
- 직통이 없으면 **갈아탈 역을 미리 정해 두고** 그 역에서 내려 줍니다. 한 번 내린 노선에는 다시 타지 않습니다.
- 내리거나 탈 승객이 없는 역은 **서지 않고 지나갑니다.**

### 역
- 원 · 사각 · 삼각 세 종류가 랜덤 위치에 계속 생겨납니다 (처음 3개는 서로 다른 모양). 역이 늘면 카메라가 자동으로 줌아웃됩니다.
- 수용 인원 **6명**, 넘치면 **30초 타이머**가 원형 게이지로 표시됩니다.
- **환승역**으로 승격하면 수용 인원 **10명**, 크기 1.5배, 정차 시간이 절반(1.2초 → 0.6초)이 됩니다.

### 주간 보상
- 하루는 20초, **7일마다 보상 선택창**이 열립니다.
- 기관차 1대는 무조건 받고, **노선 / 환승역 / 객차 / 고속열차** 중 랜덤 2개 중 하나를 고릅니다 (노선이 7개면 노선은 후보에서 제외).
- 노선을 삭제하면 그 노선에 배치했던 열차·객차가 **다시 인벤토리로 돌아옵니다.**

## 내가 맡은 부분 (김진아)

**노선 그리기·편집, 환승 길찾기, 주간 보상 틀, 게임 속도, 게임오버 처리**를 맡았고, 팀의 **PR 병합을 전담**했습니다.

- **노선 그리기·편집** — 마우스 입력부터 노선 생성, 45° 꺾임 경로, 손잡이로 연장·단축, 중간에 역 끼워 넣기/빼기, 하단 버튼으로 삭제, 순환선까지 구현했습니다.
  드래그 종류가 많아 마우스 입력을 **모드(새 노선 / 연장 / 중간 편집 / 열차 배치 …)로 나눈 상태 머신**으로 관리해, 모드마다 다른 규칙을 적용했습니다.
- **환승 길찾기** — 열차가 BFS로 태울 승객과 내려 줄 환승역을 정하는 구조를 만들었습니다.
  환승역에 내린 승객이 같은 열차에 다시 타는 버그는, 승객에게 "방금 내린 노선" 정보를 남겨 같은 노선에는 다시 타지 않게 해 고쳤습니다.
- **주간 보상** — 요일 진행, 보상 선택창, 자산 버튼을 만들었습니다. 보상창이 뜨면 게임을 멈추되 **직전 배속을 저장했다가 복구**해서, 2배속으로 하다가 보상을 받아도 속도가 초기화되지 않습니다.
  노선을 드래그하는 도중에 주말이 되면 보상창을 바로 띄우지 않고, 손을 뗀 뒤에 띄우도록 처리했습니다.
- **게임오버 처리** — 처음에는 카메라 스크립트가 게임오버 판정·결과 UI까지 함께 맡고 있었습니다. 이를 `GameManager`로 옮겨 **카메라는 연출만, 게임 흐름은 매니저가** 맡도록 나눴고, 게임오버 뒤에는 드래그 입력을 막았습니다.
- **기타** — 일시정지·재생·2배속 토글, 고속열차 프리팹, 삭제된 노선 구간을 열차가 다 달릴 때까지 흐리게 남겨 두는 잔상 표시, 오브젝트 그리기 순서(sortingOrder) 정리.
